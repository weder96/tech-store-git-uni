# Análise 07: O "GitHub Flow" como Padrão de Projeto

A documentação promove um fluxo de trabalho ágil e baseado em branches, conhecido como GitHub Flow.

### O Ciclo de Vida:
1. Criar branch a partir da `main`.
2. Adicionar commits.
3. Abrir Pull Request para discussão.
4. Realizar testes e CI/CD.
5. Fazer o Merge e deletar a branch.
