# Análise 02: O Método "Hello World" de Aprendizado

O guia prático "Hello World" é a porta de entrada recomendada. Ele foca em ensinar o fluxo de trabalho (workflow) antes mesmo de aprofundar em comandos complexos.

### Etapas Analisadas:
1. **Criação de Repositório:** O conceito de "container" para projetos.
2. **Criação de Branch:** Introdução ao isolamento de alterações.
3. **Commits:** O registro histórico de mudanças.
4. **Pull Requests:** A essência da colaboração no GitHub (revisão e discussão).
